# Repository Presentation

This repository is intended to be understandable in under one minute by a developer, product manager, or technical reviewer who has never seen Spark Desktop before.

## Recommended GitHub About metadata

**Description**

`A focused Windows desktop shell for Gemini Spark with native tabs, Google Workspace continuity, persistent sessions, and signed automatic updates.`

**Topics**

`tauri`, `rust`, `react`, `typescript`, `webview2`, `windows`, `desktop-app`, `gemini`, `gemini-spark`, `google-workspace`, `auto-update`

Show **Releases** on the repository home page. Hide empty Deployments/Packages sections unless they become real distribution channels.

## Visual assets to prepare

The next high-value presentation asset is a public-safe demo, not more decorative repository chrome.

Recommended assets:

1. one clean hero screenshot showing Spark + the native tab bar;
2. one screenshot showing a Google Sheet or Doc opened as an internal tab using non-sensitive demo content;
3. one 20–40 second GIF/video showing Spark → Workspace tab handoff → tab switching → window controls;
4. optional simple architecture diagram generated from the Mermaid model in README.

Do not publish screenshots containing private accounts, documents, emails, prompts, avatars, phone numbers, or other personal information.

## Positioning rule

Use:

**Spark Desktop — an independent Windows desktop shell for Gemini Spark.**

Avoid wording or graphics that suggest Spark Desktop is an official Google/Gemini application or partner product.
